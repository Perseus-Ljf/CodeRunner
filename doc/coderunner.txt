1. Introduction                                      *coderunner-introduction*

CodeRunner sends Python/Julia code cells, Tree-sitter code items, or visual
selections from any filetype to a toggleterm.nvim terminal.

Cell and Tree-sitter commands are enabled only for `python` by default.
Enable Julia with:
>
  require("coderunner").setup({
    enabled_filetypes = { "python", "julia" },
  })
<
Visual selection commands work in every filetype regardless of this list.

Cell commands find the current cell by scanning for language-specific markers.
Python and Julia use `# %%`. MATLAB uses `%%`. Blank lines and comment-only
lines are removed before the code is sent to the terminal.

Tree-sitter commands find the current Python or Julia code item. In Python,
the whole nearest function or class is sent; otherwise the current statement
is sent. Julia supports long/short-form functions, where signatures, anonymous
functions, macro/type/module definitions, macro wrappers and do blocks. Outside
a definition, the current standalone expression or statement is sent. A control
flow header selects the complete statement; its body selects the current item.
Tree-sitter execution preserves indentation, blank lines and comments.

Visual selections support characterwise, linewise and blockwise modes. Selected
text is sent without removing indentation, tabs, trailing spaces, blank lines
or comments. Tabs cut by a block follow native Neovim yank behavior. Registers
and clipboard settings are restored after extraction. Selection commands do
not jump, regardless of the jump option.

A new terminal uses languages[filetype].start_cmd if configured. Unconfigured
filetypes use the default shell for selection sending, not the Python REPL.
Existing terminals are reused without checking which interpreter is running;
use separate terminal ids for different languages. The receiving interpreter
must support the submitted code; selection sending does not compile it.

==============================================================================
2. Requirements                                      *coderunner-requirements*

- Neovim 0.8+
- toggleterm.nvim
- A Python or Julia Tree-sitter parser for |:RunCurrentLine|
- The configured interpreter executable in Neovim's environment

Cell and visual selection commands do not require a Tree-sitter parser.

==============================================================================
3. Commands                                              *coderunner-commands*

                                                        *:CodeRunBlock*
:CodeRunBlock [args]
        Send the current code cell to toggleterm.

                                                        *:CodeRunCell*
:CodeRunCell [args]
        Alias of |:CodeRunBlock|.

                                                        *:CodeRunCurrentLine*
:CodeRunCurrentLine [args]
        Send the current Tree-sitter code item to toggleterm.

                                                        *:RunCurrentLine*
:RunCurrentLine [args]
        Alias of |:CodeRunCurrentLine|.

                                                        *:CodeRunSelection*
:'<,'>CodeRunSelection [args]
        Send the visual selection to toggleterm, preserving whitespace.
        Works in all filetypes, even outside enabled_filetypes.
        Supports v, V and CTRL-V selections and preserves selected columns.
        Without a range, uses the live or most recent visual selection in the
        current buffer. Explicit ranges (e.g. :2,5CodeRunSelection) send complete
        lines unless they match the most recent visual marks, in which case
        that selection is used. Whitespace-only selections are not sent.
        The jump option is ignored.

Arguments are whitespace-separated:
>
  1, 2, term=2     target toggleterm id
  show, hide       show or hide the terminal after sending code
  jump, nojump     move to the next cell or Tree-sitter item, or stay put
<

Examples:
>
  :CodeRunBlock show jump
  :CodeRunBlock hide nojump
  :CodeRunBlock term=2 show=false jump=false
  :RunCurrentLine term=2 show nojump
  :'<,'>CodeRunSelection term=2 show
<

4. Configuration                                  *coderunner-configuration*

>
  require("coderunner").setup({
    term_id = 1,
    startup_delay = 500,
    show_terminal = true,
    jump = true,
    notify = true,
    enabled_filetypes = { "python" },
    languages = {
      python = {
        cell_marker = "^%s*# %%",
        comment = "^#",
        start_cmd = "sipy",
      },
      matlab = {
        cell_marker = "^%s*%%",
        comment = "^%%",
        start_cmd = "matlab -nodisplay",
      },
      julia = {
        cell_marker = "^%s*# %%",
        comment = "^#",
        start_cmd = "julia",
      },
    },
  })
<

You can add or override entries in `languages` for any Neovim filetype.

5. Keymaps                                                *coderunner-keymaps*

CodeRunner does not create keymaps internally. Use Neovim's normal keymap API:
>
  vim.keymap.set("n", "<leader>rb", "<cmd>CodeRunBlock show jump<cr>", {
    desc = "Run current code cell",
  })

  vim.keymap.set("n", "<leader>rl", function()
    require("coderunner").run_line("show nojump")
  end, {
    desc = "Run current Tree-sitter item",
  })

  vim.keymap.set("n", "<leader>rL", function()
    require("coderunner").run_line("hide jump term=2")
  end, {
    desc = "Run current Tree-sitter item in background",
  })

  vim.keymap.set("x", "<leader>rs", function()
    require("coderunner").run_selection("show term=2")
  end, {
    desc = "Send selected code",
  })
<

Lua helpers accept the same argument string as commands:
>
  require("coderunner").run_block("hide nojump")
  require("coderunner").run_line("term=2 show jump")
  require("coderunner").run_selection("term=2 show")
<

The lower-level send_selection helper also accepts an options table:
>
  require("coderunner").send_selection({
    term_id = 2,
    show_terminal = true,
  })
<

6. Julia Workspace                                      *coderunner-workspace*

                                                        *:CodeRunWorkspace*
:CodeRunWorkspace [term=N] [attach]
        Toggle a read-only Julia workspace sidebar for the selected terminal.
        Defaults to the configured term_id. Starts languages.julia.start_cmd
        if the terminal does not exist. Julia terminals started by CodeRunner
        in this Neovim session are recognized automatically. For an existing,
        unrecognized Julia REPL, use attach to confirm the interpreter.

                                                        *:CodeRunWorkspaceRefresh*
:CodeRunWorkspaceRefresh [term=N] [attach]
        Refresh the selected workspace, or the current sidebar's session if
        no terminal is given. Use attach to reconnect to an existing Julia
        process after disconnection or restart.

                                                        *:CodeRunWorkspaceDisconnect*
:CodeRunWorkspaceDisconnect [term=N]
        Disconnect the current workspace without stopping Julia. The sidebar
        keeps the last snapshot and displays its disconnected status.

Use attach only with an idle, local Julia REPL, not a shell, another language,
a remote SSH session, or a partially entered expression. CodeRunner loads a
standard-library helper into that process over terminal input. Variables are
returned over an authenticated loopback TCP connection, not terminal output.
No Julia packages are installed and user project files are not modified.

The sidebar shows Main's global variables, their types, built-in array sizes,
and bounded previews. Modules, internal names and explicitly imported bindings
are excluded. Custom display/property methods are not invoked; custom objects
show <preview omitted>. Arrays preview the first six elements in column-major
linear order. Function locals, tree expansion, table views, remote processes
and automatic refresh are not implemented in this version.

Sidebar mappings:
  r           refresh
  <CR>        view the selected variable's summary in a floating window
  q           close the sidebar, keeping Julia and its connection alive

Connections and refreshes have a timeout; an unresponsive Julia process never
blocks Neovim. Timeout/disconnect preserves the last complete snapshot with its
status and timestamp. Refresh may be delayed during a long non-yielding Julia
calculation; a timeout does not cancel or interrupt Julia code. Confirm the
interpreter again with attach after process exit or replacement.

Optional configuration (defaults):
>
  require("coderunner").setup({
    workspace = {
      width = 52,             -- 24..200 columns
      position = "right",     -- "left" or "right"
      timeout = 15000,        -- 100..120000 milliseconds
      max_items = 500,        -- 1..2000 variables
      preview_length = 120,  -- 16..512 characters, plus truncation marker
    },
  })
<
A '+' after the variable count indicates the snapshot reached max_items.
Workspace commands do not require Tree-sitter or enabled_filetypes. Nothing
is loaded into Julia until a workspace command requests a connection. Each
terminal has an independent snapshot. Tested with Julia 1.12.6.
